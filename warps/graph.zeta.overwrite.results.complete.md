# Four-color zeta overwrite results

publish: graph.zeta.overwrite

The Graphics project built successfully. The WinForms button and the PNG preview command call the same renderer. The preview command ran successfully with the installed .NET 7 Windows Desktop runtime using major-version roll-forward.

Winning colors changed on 69.5% of pixels under grid refinement and 98.0% after shifting the fine grid by half a step on both axes. Traversing the fine grid in reverse preserved owners, colors and all competing quadrant votes. Local colors followed the stamp grid in this window. With a fixed output origin at zero, the winding estimate was 1 at both 32 and 64 samples around the known zero and 0 at both resolutions around the off-line control. This is a floating-point visualization experiment with heuristic loop sampling.

The original forward-difference evaluator took 108 ms for the zeta grid on one run. Five optimized runs took 25–54 ms (median 43 ms) after collecting the Euler-transformed eta coefficients once. Four stamp passes, including the reversed comparison, took 12–18 ms. Times exclude the final bitmap painting.
